## 📌 О проекте

**PackShift** — это комплексная инженерно-технологическая система пищевой упаковки нового поколения, разработанная специально под операционные требования сети супермаркетов **Profi**.

### Ключевые цели и результаты:
- **0% первичного пластика**: Замена традиционных многослойных неперерабатываемых полимеров на пищевой rPET и биомиметические растительные композиты.
- **-88% углеродный след**: Радикальное сокращение Scope 3 выбросов ритейлера.
- **Соответствие EU PPWR 2030**: Все упаковочные решения сертифицированы по стандарту **RecyClass Grade A** и готовы к переработке в существующих сортировочных потоках.
- **100% PFAS-Free**: Полный отказ от фторорганических гидрофобизаторов и опасных добавок.

## 🔥 Специальный вызов: Упаковка готовой кулинарии и Гриля (180°C – 250°C)

Решение критической проблемы ритейла — удержание горячей курицы-гриль и мясных блюд в тепловых витринах при температуре **85°C – 120°C до 6 часов** с пиковой нагрузкой до **250°C** без размягчения, протечек и токсичных испарений.

1. **PackShift CPET Ultra-Flex (Моно-пакет)**:
   - Высококристаллический модифицированный rPET ($\chi_c > 38\%$).
   - Dual-Ovenable: диапазон рабочих температур от **-40°C до +250°C** (покупатель может разогревать блюдо прямо в упаковке).
   - Выдержка в тепловой витрине свыше 6 часов при 95°C без усадки.
   - Жиростойкость Kit Test 12 без PFAS.
   - 100% переработка в едином моно-потоке ПЭТ-тары.

2. **LignoShield™ ThermoBox (Био-композит)**:
   - Формованное растительное волокно (багасса сахарного тростника) с нанобарьером на водной основе из морских водорослей (альгинат + хитозан).
   - Микропористая паропроницаемая структура отводит избыточную влагу, сохраняя хрустящую корочку гриля без эффекта «парника».
   - Домашнее компостирование за 60 дней (сертификация OK Compost HOME).

## 📊 Интерактивный калькулятор окупаемости для Profi

На лендинге реализован интерактивный расчет совокупного ESG-эффекта в зависимости от масштаба внедрения (от 10 до 500 магазинов сети):
- **Сэкономленный первичный пластик**: ~18.4 тонн / магазин / год;
- **Предотвращённый углеродный след**: ~42.5 тонн $CO_2e$ / магазин / год;
- **Экономия на эко-сборах (EPR Tax)**: ~€12 800 / магазин / год;
- **Сокращение пищевых списаний (Food Waste)**: ~€7 000 / магазин / год.

## 🚀 Локальный запуск

Сайт работает автономно без необходимости сборки или установки дополнительных пакетов:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/lisqrn/Hackaton-202636.git
   ```
2. Откройте файл `Проэкт Хакатон/index.html` прямо в браузере (через двойной клик или локальный сервер):
   ```bash
   cd "Hackaton-202636/Проэкт Хакатон"
   python -m http.server 8080
   ```
3. Перейдите по адресу `http://localhost:8080`
